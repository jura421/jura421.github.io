Aplikace MSE střih · poslední úprava: 19. 11. 2026

Kdo aplikaci provozuje

MSE střih je osobní nástroj správce farního YouTube kanálu. Běží na jeho vlastním domácím serveru (NAS) a nemá žádné další uživatele.

K čemu aplikace přistupuje

Po souhlasu majitele kanálu aplikace používá YouTube Data API s oprávněním youtube.force-ssl, a to jen k tomu, aby nahrála video na jeho kanál a přidala je do jeho playlistu. K ničemu jinému se oprávnění nepoužívá.

Jaké údaje se ukládají

  • Přihlašovací token (refresh token) k účtu majitele kanálu. Je uložen pouze v souboru na jeho serveru.
  • Záznamy a titulky z jeho vlastního kanálu, které se zpracovávají na jeho serveru a po nahrání výstřižku se mažou.

Aplikace neshromažďuje údaje o jiných lidech, nepoužívá analytiku ani reklamy a žádné údaje neprodává, nesdílí ani nepředává třetím stranám.

Google API Services User Data Policy

Používání a předávání informací získaných z Google API aplikací MSE střih odpovídá Zásadám Google API Services User Data Policy, včetně požadavků na omezené použití (Limited Use).

Jak přístup odvolat a údaje smazat

Přístup lze kdykoli odvolat na myaccount.google.com/permissions. Smazáním souboru s tokenem na serveru se odstraní všechna uložená přihlášení.

Privacy policy (English)

MSE střih is a personal tool run by the administrator of a parish YouTube channel on his own home server. With the channel owner’s consent it uses the YouTube Data API (scope youtube.force-ssl) only to upload a video to the owner’s own channel and add it to the owner’s playlist.

The only data stored is an OAuth refresh token for the owner’s account, kept in a file on that server, and temporary copies of the owner’s own recordings and captions, which are deleted after the clip is uploaded. The app collects no data about other people, uses no analytics or advertising, and does not sell, share or transfer data to third parties.

The app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
